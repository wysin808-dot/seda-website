学校概况

诺雅初级学院（Eunoia Junior College，简称 EJC）于 2017 年正式开学，是新加坡最年轻的初级学院。学校由三所历史悠久的 IP 中学联合创办：CHIJ St Nicholas Girls' School（圣尼各拉女校）、Catholic High School（公教中学）和 Singapore Chinese Girls' School（新加坡华人女子中学）。

EJC 位于新民路（Sin Ming Place），校园设计现代，设施先进。学校名称"Eunoia"来自古希腊语，意为"美好的思想"，体现了学校追求卓越思维和品格的教育理念。

虽然建校时间短，但 EJC 凭借三所优秀中学的 IP 学生基础和创新教育理念，迅速跻身新加坡顶尖 JC 之列。学校的 A-Level 成绩在首届毕业生中即表现优异。

课程体系

EJC 提供 GCE A-Level 课程及六年制 Integrated Programme（IP）。IP 学生来自三所合作中学，约占学生总数的 70%；其余 30% 通过 JAE（O-Level 成绩）录取。

H2 科目涵盖数学、进阶数学、物理、化学、生物、经济学、历史、地理、文学、中华文学、Art、音乐等。学校注重跨学科学习，提供 World Readiness Programme 培养学生的全球视野和批判性思维。特色课程还包括 H3 研究论文和大学合作模块。

入学要求

EJC 的 COP 通常为 L1R5 原始分 6-7 分。由于学校约 70% 名额分配给 IP 直通车学生，JAE 的竞争较为激烈，实际录取分数可能略高。

国际学生可通过 O-Level 成绩申请 JAE 名额。需注意 EJC 的 JAE 名额有限，建议 O-Level 成绩尽量优异以增加录取机会。DSA 申请也对外开放。

特色项目

EJC 的 World Readiness Programme 是学校的核心特色，培养学生面对复杂全球问题的能力。课程融合设计思维、跨文化理解和社会创新，让学生在真实项目中学以致用。

学校还注重科技创新教育，提供数据科学、人工智能和创业相关的工作坊和项目。表演艺术方面，EJC 的各 CCA 虽然年轻但发展迅速，在 SYF 中已有出色表现。学校还与海外学校建立了多项交流合作关系。

中国学生须知

EJC 的三所 IP 合作中学中有两所是华文背景学校（公教中学和新加坡华人女校），因此学校整体有良好的华文文化氛围。对于通过 JAE 进入的中国学生，融入相对顺畅。

需注意 EJC 的 JAE 名额有限（约 30%），竞争比同 COP 水平的其他 JC 更激烈。学校位于新民区域，靠近碧山（Bishan），交通便利。EJC 的教育理念现代创新，适合思维活跃、追求全面发展的中国学生。

常见问题

EJC 是新建学校，教学质量有保证吗？

EJC 虽然 2017 年才成立，但其师资来自新加坡各顶尖 JC，教学经验丰富。首届毕业生的 A-Level 成绩即表现优异。更重要的是，70% 的学生来自三所顶尖 IP 中学，学生基础非常好。

非 IP 学生在 EJC 会不会很吃力？

不会。EJC 对 JAE 学生有专门的衔接支持计划，帮助他们快速适应 JC 学习节奏。从实际情况看，JAE 学生与 IP 学生在 A-Level 中表现相当，两个群体也能很好地融合。

EJC 的地理位置方便吗？

EJC 位于 Sin Ming Place，靠近 Bishan MRT（NS 线和 CC 线交汇）和 Marymount MRT（CC 线）。交通非常便利，周边有多个商场和餐饮选择。
