AEIS（Admissions Exercise for International Students）是国际学生进入新加坡政府中小学的唯一统考通道。每年报名窗口仅开放约三周，错过意味着再等半年甚至一年。费用方面，小学组S$672起，中学组按年级递增——但报名费之外还有护照公证、翻译认证等隐性成本。以下用七张表拆解全部费用构成和报名细节。

## AEIS 考试费用明细（2026年标准）

AEIS 报名费由新加坡考试与评鉴局（SEAB）统一收取，不含GST。小学组和中学组费用不同，且中学组按申请年级递增。

| 申请组别 | 申请年级 | 报名费（不含GST） | 折合人民币（约） |
|---------|---------|-----------------|-----------------|
| 小学组 | P2/P3 | S$672.00 | ¥3,560 |
| 小学组 | P4/P5 | S$672.00 | ¥3,560 |
| 中学组 | Sec 1 | S$800.00 | ¥4,240 |
| 中学组 | Sec 2 | S$900.00 | ¥4,770 |
| 中学组 | Sec 3 | S$930.00 | ¥4,930 |

需要注意的是，AEIS 不允许同时申请多个年级——每次报名只能选择一个目标年级。如果考试未通过，下次报名需重新缴费，费用不退。

## 隐形成本：报名费之外的支出

报名费只是冰山一角。以下是在考试前必须完成的配套支出：

| 费用项目 | 金额范围（S$） | 备注 |
|---------|--------------|------|
| 护照信息页公证翻译 | S$30–80 | 非英文护照必须翻译公证 |
| 出生证明翻译公证 | S$30–80 | 中文出生证需翻译 |
| 最近两年学校成绩单翻译 | S$50–150/份 | 需由认证翻译机构出具 |
| 护照照片（白底） | S$10–20 | 新加坡本地拍费用，中国约¥30 |
| DSA/医疗证明（如需） | S$0–200 | 特殊需求考生额外材料 |
| 签证/入境费用（如需现场考试） | S$30–100 | 仅海外考生赴新考试时产生 |
| **额外费用合计** | **S$150–630** | 折合人民币 ¥800–3,340 |

对于大多数中国家庭，额外费用在 S$200–400（¥1,060–2,120）区间。建议预留 S$1,000（¥5,300）作为单次报名总预算。

## AEIS 报名时间线

AEIS 每年仅开放一次报名窗口，集中在7月。S-AEIS（补充考试）在次年1月开放，但仅限小学P2–P4和中学Sec 1–Sec 2。

| 阶段 | AEIS（9月考期） | S-AEIS（次年2月考期） |
|------|----------------|---------------------|
| 报名窗口开放 | 7月初 | 1月初 |
| 报名窗口关闭 | 7月底（约3周） | 1月下旬（约2周） |
| 准考证发放 | 8月下旬 | 2月中旬 |
| 考试日期 | 9月中下旬 | 2月下旬 |
| 成绩公布 | 12月中旬 | 4月下旬 |
| 入学时间 | 次年1月 | 同年5–6月（插班） |

报名窗口非常短，且名额有限。SEAB 官网在报名开放当天可能会因流量过大而响应缓慢，建议提前准备好全部材料，窗口一开立即提交。

## 报名材料清单（一步齐全）

材料不全是最常见的报名失败原因。以下按必需/选填分类：

| 材料 | 必需/选填 | 格式要求 | 常见错误 |
|------|----------|---------|---------|
| 考生护照信息页 | 必需 | PDF/JPG，小于2MB | 护照过期未更新 |
| 考生出生证明 | 必需 | 英文或英文翻译件 | 仅提交中文原件未翻译 |
| 考生护照照片 | 必需 | 白底，400×514像素 | 蓝底或红底被退回 |
| 最近两年成绩单 | 必需 | 英文翻译件 | 学校盖章缺失 |
| 父母护照信息页 | 选填（建议提供） | PDF/JPG | 信息与报名表不一致 |
| 新加坡家属准证/长期探访准证 | 如有则需提供 | PDF | 准证过期 |
| 医疗/特殊需求证明 | 仅特殊需求考生 | 英文医生证明 | 非英文未翻译 |

所有非英文文件必须由认证翻译机构或公证处翻译。自行翻译的材料一律不被接受。

## 新加坡考场 vs 海外考场：怎么选

AEIS 考试仅在新加坡举行。海外没有 AEIS 考场——这是很多家长的第一大误解。所有考生必须赴新加坡参加考试。

| 对比维度 | 新加坡考场（唯一选项） |
|---------|---------------------|
| 考试地点 | 新加坡博览中心（Singapore Expo）为主考场 |
| 交通建议 | 地铁蓝线/绿线 Expo 站，步行5分钟 |
| 住宿建议 | 樟宜机场附近或东海岸区域，提前2-3天到达 |
| 所需签证 | 旅游签证（通常可停留30天），建议申请多次往返 |
| 家长陪同 | 必须父母一方或监护人陪同，未成年不能独自入境 |
| 考前一天 | 建议实地踩点，确认考场楼栋和教室分布 |

## AEIS 报名常见错误与避坑指南

| 常见错误 | 后果 | 正确做法 |
|---------|------|---------|
| 报名截止当天提交 | 系统拥堵导致提交失败 | 窗口开放前3天完成提交 |
| 护照信息与报名表不一致 | 报名被退回 | 严格按护照页逐字母填写 |
| 成绩单缺少学期信息 | 资格审核不通过 | 成绩单必须完整覆盖最近两年 |
| 选错年级（高于实际年龄对应） | 自动被拒 | 对照 SEAB 年龄-年级对照表 |
| 未保存确认邮件 | 无法查询申请状态 | 截图保存并打印纸质版 |
| 付款失败未重试 | 报名未完成 | 确认收到 SEAB 付款确认邮件 |
| 照片不符合规格 | 自动退回 | 严格按 400×514 像素白底 |
| 报名后更换护照 | 信息不一致无法入场 | 报名期间护照有效期须覆盖考试日期 |

## 报名成功后的时间规划

| 时间节点 | 行动项 | 备注 |
|---------|-------|------|
| 报名确认后1周内 | 预订机票和住宿 | 考试日期前3天抵达新加坡 |
| 报名后1个月内 | 申请新加坡签证 | 建议申请多次往返，有效期更长 |
| 准考证发放后 | 打印3份准考证 | 1份随身、1份备用、1份家长保存 |
| 考前2周 | 确认考场地址和路线 | Singapore Expo 为主考场 |
| 考前1周 | 准备考试文具 | 2B铅笔、橡皮、黑色签字笔、透明笔袋 |
| 考前一天 | 实地踩点 | 确认楼栋、教室、洗手间位置 |
| 考试当天 | 提前1小时到达 | 携带护照原件和准考证 |

## 常见问题

### AEIS 报名费可以退吗？

不可以。AEIS 报名费一经缴纳不予退还，无论是否参加考试或是否通过。这也是建议考生充分准备后再报名的原因——多次试考不仅成本高（每次 S$672–930），还会在孩子心理上产生压力。

### 可以用父母的信用卡付款吗？

可以。SEAB 报名系统接受 Visa、MasterCard 信用卡和借记卡在线付款。需要在报名时输入卡号、有效期和 CVV。部分中国发行的银行卡可能需要开通境外在线支付功能。

### 报名后可以改年级吗？

不可以。提交报名后年级不可更改。如果发现选错年级，唯一的办法是取消当前申请（费用不退）并重新报名——前提是报名窗口仍未关闭。

### AEIS 和 S-AEIS 可以同时报名吗？

不可以。每次只能选择一个考试批次报名。如果 AEIS 未通过，可以在次年1月报名 S-AEIS（但 S-AEIS 仅开放部分年级）。

### 没有护照可以先用身份证报名吗？

不可以。AEIS 报名系统仅识别护照作为身份证明。所有国际考生的身份核验均以护照为准。如果护照正在办理中，必须在报名窗口关闭前拿到护照并完成报名。

### 报名时显示名额已满怎么办？

AEIS 各年级名额有限，先到先得。如果目标年级名额已满，可以考虑：(1) 降低一个年级报名（如目标 P4 满额可报 P3）；(2) 等待下一次考试批次（S-AEIS）；(3) 通过 [国际学校路径](/international-school/how-to-choose/) 作为备选方案。

### 报名后多久能收到准考证？

通常在报名窗口关闭后约4周，SEAB 会通过电子邮件发送准考证。如8月底仍未收到，应及时通过 SEAB 官网联系客服——邮箱地址在报名确认邮件中。

### 可以用旅游签证参加考试吗？

可以。绝大多数海外考生使用新加坡旅游签证入境参加考试。签证需在入境前办理，建议通过新加坡驻华使领馆或授权签证代理申请。考试期间（含考前准备）建议在新加坡停留5-7天。

### AEIS 报名对家长签证有要求吗？

考生本人需持有有效签证，陪同家长同样需要办理签证。未成年考生入境时，移民局可能要求出示监护人关系证明（出生证明翻译件），建议随身携带。
