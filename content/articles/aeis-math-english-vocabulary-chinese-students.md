中国学生在AEIS数学考试中面临的真正挑战，往往不是数学功底本身——大部分考生的数学水平远超新加坡同龄标准——而是全英文的考试语言。一个在国内轻松解出二次方程的学生，可能因为读不懂"quadratic equation"而卡在第一步。根据近年辅导数据，**因术语理解偏差导致的非知识性失分，平均占总失分的35%-40%**。本文将数学英文词汇按考试场景分类整理，帮助考生系统性扫清语言障碍。

## 为什么数学词汇是最大的"隐形失分点"

AEIS数学的命题语言是标准英式英语，与中国课堂的中文数学环境存在系统性隔离。三大断层尤为突出：

| 断层类型 | 典型表现 | 考试后果 |
|----------|---------|---------|
| **术语不认识** | 知道"垂直"但不知道"perpendicular" | 题干完全读不懂 |
| **一词多义** | "product"以为是"产品"，实际是"乘积" | 理解方向错误 |
| **指令词混淆** | "simplify"和"solve"分不清 | 答题方法错误 |

如想系统了解AEIS数学的整体难度框架，可参考[AEIS数学难度相当于国内几年级](/aeis/aeis-math-difficulty-china-grade/)及[AEIS备考时间线](/aeis/aeis-preparation-timeline/)。对数学和英文难度的横向比较，见[AEIS数学和英文哪个更难](/aeis/aeis-math-vs-english-difficulty/)。

## 四大核心运算术语中英对照

以下术语覆盖AEIS数学试卷中约70%的运算类题干。

| 英文术语 | 中文含义 | 符号/示例 | 易错提醒 |
|---------|---------|----------|---------|
| addition / add | 加法 / 加 | 3 + 5 = 8 | "plus"在口语中也表"加" |
| subtraction / subtract | 减法 / 减 | 8 - 3 = 5 | "minus"为介词用法，"subtract"为动词 |
| multiplication / multiply | 乘法 / 乘 | 4 × 6 = 24 | "times"是口语化表达，"product"是结果 |
| division / divide | 除法 / 除 | 24 ÷ 6 = 4 | "quotient"是商，注意与"divide"区分 |
| sum | 和（加法结果） | 3 + 5 = 8 → sum=8 | 不指"总和"时可以指"任意和" |
| difference | 差（减法结果） | 8 - 3 = 5 → difference=5 | 不是"不同之处" |
| product | 积（乘法结果） | 4 × 6 = 24 → product=24 | ⚠️ 高频陷阱——不是"产品" |
| quotient | 商（除法结果） | 24 ÷ 6 = 4 → quotient=4 | 容易与"equation"混淆 |
| remainder | 余数 | 25 ÷ 6 = 4 R1 | 小学段必考概念 |
| evaluate | 求值 | Evaluate 3x when x=5 | 不是"评估"，是"代入计算" |

## 几何图形与空间术语对照

几何题是术语误读的重灾区——图形本身不难，但读不懂描述无法下手。

| 英文术语 | 中文含义 | 考试场景 |
|---------|---------|---------|
| triangle | 三角形 | isosceles triangle（等腰三角形）、equilateral triangle（等边三角形） |
| quadrilateral | 四边形 | square（正方形）、rectangle（长方形）、parallelogram（平行四边形） |
| perpendicular | 垂直 | 符号⊥，two lines are perpendicular |
| parallel | 平行 | symbol ∥，parallel lines never meet |
| bisect | 平分 | angle bisector（角平分线）、perpendicular bisector（垂直平分线） |
| circumference | 周长（圆的） | 与perimeter区分：圆用circumference |
| perimeter | 周长（多边形的） | 多边形周边长度总和 |
| area | 面积 | 单位用 square units |
| volume | 体积 | 单位用 cubic units |
| radius / diameter | 半径 / 直径 | diameter = 2 × radius |
| clockwise / anticlockwise | 顺时针 / 逆时针 | 旋转和方向题高频词 |
| acute / obtuse angle | 锐角 / 钝角 | acute < 90° < obtuse < 180° |
| hypotenuse | 斜边 | 直角三角形中最长的一边，仅用于right-angled triangle |

## 最容易混淆的术语陷阱

以下术语在日常英语和数学英语中含义完全不同，是中国考生最常踩的坑。

| 英文术语 | 日常含义 | 数学含义 | 考试示例 |
|---------|---------|---------|---------|
| mean | 意思是/刻薄 | 平均数（算术平均） | Find the mean of 3, 5, 7 → 求平均数 |
| table | 桌子 | 表格 | Complete the table below |
| figure | 数字/人物 | 图形/图表 | In the figure above... |
| power | 力量/电源 | 幂/次方 | 2 to the power of 3 = 8 |
| root | 根 | 根/方根 | square root（平方根）、cube root（立方根） |
| term | 学期/术语 | 项（代数中的一项） | How many terms in 3x + 2y - 5? |
| expression | 表达 | 表达式 | Simplify the expression 2x + 3x |
| equation | 等式/方程式 | 方程 | Solve the equation 2x + 1 = 7 |
| value | 价值 | 数值 | Find the value of x |
| constant | 持续的 | 常数 | 如 π（pi）≈ 3.14159 |

## 代数与函数核心术语

进入中学组（Sec 1-3）后，代数类术语占比快速上升。

| 英文术语 | 中文含义 | 说明 |
|---------|---------|------|
| variable | 变量 | 通常用x, y, z表示 |
| coefficient | 系数 | 如3x中"3"是coefficient of x |
| solve | 解（方程） | Solve for x → 解出x的值 |
| simplify | 化简 | Simplify 2x+3x → 5x（不是求解） |
| expand | 展开 | Expand (x+2)(x+3) = x²+5x+6 |
| factorise | 因式分解 | Factorise x²-4 = (x+2)(x-2) |
| substitute | 代入 | Substitute x=3 into the expression |
| inequality | 不等式 | x > 5（大于）、x ≤ 10（小于等于） |
| simultaneous equations | 联立方程组 | 两个或以上方程同时满足 |
| gradient / slope | 斜率/坡度 | y = mx + c中m即gradient |
| intercept | 截距 | y-intercept（y轴截距）、x-intercept（x轴截距） |

## 考试题干高频指令词

读懂题目指令词是答题第一步。以下词汇出现在每套AEIS数学试卷中。

| 指令词 | 含义 | 典型题干 |
|-------|------|---------|
| Find... | 求出 | Find the value of y |
| Calculate... | 计算 | Calculate the total cost |
| Simplify... | 化简 | Simplify the expression below |
| Solve... | 解 | Solve the equation |
| Evaluate... | 求值/代入计算 | Evaluate 2a + 3b when a=1, b=2 |
| Express... | 表示为 | Express your answer as a fraction |
| Hence... | 因此/利用上题结果 | Hence find the value of x |
| Show that... | 证明/说明 | Show that the triangle is right-angled |
| Explain... | 解释 | Explain why angle ABC = 45° |
| State... | 写出/陈述 | State the coordinates of point A |
| Round...to... | 四舍五入到 | Round your answer to 2 decimal places |
| Estimate... | 估算 | Estimate the value of 198 × 52 |

## 备考实操建议

对于正在备战AEIS数学的考生，术语积累需要贯穿备考全过程。日常训练时，建议将以下动作融入每个练习环节。

| 备考阶段 | 核心任务 | 具体方法 |
|---------|---------|---------|
| 初期（前2个月） | 建立术语库 | 每天认读10-15个数学英文术语，按运算/几何/代数分类 |
| 中期（3-4个月） | 题干脱敏 | 用全英文试卷做计时训练，标记每次不懂的术语并整理成错词表 |
| 后期（考前1个月） | 指令词强化 | 专门训练指令词识别速度——看到"evaluate"立刻反应"代入求值" |

备考自学的优劣势分析可参考[AEIS备考自学还是报班](/aeis/aeis-self-study-vs-tuition/)。数学专项备考策略见[AEIS数学怎么备考](/aeis/aeis-math-preparation/)。

## 常见问题

### AEIS数学看不懂题目怎么办？考场上可以查字典吗？
AEIS考试不允许携带任何翻译工具或字典进入考场。如果遇到不认识的术语，只能依靠上下文推测。因此，**考前术语积累是唯一有效的解决方案**。建议优先掌握本文表格中的高频术语——运算类（sum/product/quotient/difference）和指令词（find/calculate/simplify/solve）是最高优先级的必学词汇。

### 中国学生数学好，是不是背熟术语就能拿高分？
术语只是"读懂题"的第一步。AEIS数学的部分题型——如**英文应用题的阅读理解**和"Show that/Explain"类**证明解释题**——还需要一定程度的英文表达能力。尤其是中学组考试中，"Explain your answer"类题目占比约15%-20%，这需要考生不仅理解术语，还能用英文写出逻辑清晰的推理过程。英文综合能力的提升建议参考[AEIS英文怎么准备](/aeis/aeis-english-preparation/)。

### AEIS小学数学和中学数学的英文术语要求有多大差别？
差异主要体现在两个方面：一是词汇量（小学约150-200个数学术语，中学约300-400个）；二是术语深度（小学多为名词类——triangle、fraction，中学增加大量动词和抽象术语——factorise、simultaneous、gradient）。具体差异程度可参考[AEIS小学和中学考试难度差多少](/aeis/aeis-primary-vs-secondary-difficulty/)。

### "evaluate"、"calculate"、"solve"到底有什么区别？
三者在中文里都可译为"计算/求"，但在AEIS数学中用法有明确区分：**evaluate** = 代入特定值后求结果（如"Evaluate 3x when x=2"）；**calculate** = 执行纯运算（如"Calculate 15% of 200"）；**solve** = 解方程、方程组或不等式。混用这三个词会导致答题方向错误——solve一个表达式而非方程，本质上是没有理解题目在问什么。

### 分数和小数相关的术语有哪些容易混淆的？
错误率最高的是**numerator/denominator**（分子/分母）的颠倒——国内习惯"先读分母后读分子"（如"三分之二"先读"三"），而英文"two-thirds"是先读分子，底层思维顺序相反。另一个高频错误是**improper fraction vs mixed number**——"improper fraction"（假分数，如7/4）不等于"错误分数"，"mixed number"（带分数，如1¾）不等同于"混合数字"。分数的具体计算技巧见[AEIS数学怎么备考](/aeis/aeis-math-preparation/)。

### 考前一个月突击数学词汇来得及吗？
对于数学基础扎实（国内同年级中上水平）的考生，考前一个月**集中突击术语**通常可以覆盖80%以上的考试词汇。具体做法：每天2小时，前两周扫清运算与几何术语，第三周攻克代数术语和指令词，最后一周做5套以上全英文模考卷检测术语熟悉度。时间安排参考[AEIS备考时间线](/aeis/aeis-preparation-timeline/)。

### AEIS数学考试需要写英文答题过程吗？
小学组（P2-P5）以选择题和填空题为主，对英文书写要求较低。中学组（Sec 1-3）包含应用题和证明解释题，**需要写出完整的英文解题步骤**。"Show your working"（展示计算过程）和"Explain your reasoning"（解释你的推理）是中学组的常见要求。这意味着术语掌握之外，还需要基本的数学英文书写能力。
