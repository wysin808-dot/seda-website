常见问题

新加坡有几所理工学院？分别是哪几所？
共 5 所公立理工学院：新加坡理工学院（SP，1954）、义安理工学院（NP，1963）、南洋理工学院（NYP，1992）、淡马锡理工学院（TP，1990）、共和理工学院（RP，2002）。全部由政府资助、颁发受 NUS/NTU/SIT 等公立大学认可的 Diploma 文凭，与私立大专、培训机构不同。
理工学院（Poly）和初级学院（JC）怎么选？
JC 是 2 年纯学术、考 A-Level 冲公立大学的路线，适合成绩拔尖、目标 NUS/NTU 直入的学生；理工是 3 年专业 + 实习、拿 Diploma 的路线，更偏实践、就业与升学两条腿走路。想早点接触专业、动手能力强、或想要更稳的升学缓冲，选理工更合适。
中国学生可以申请理工学院吗？需要什么条件？
可以。国际学生可凭 O-Level 或同等学历（初中/高中成绩 + AEIS 或英文测试）申请，主流通过 JAE 或各校国际学生通道。通常需要数学、英文等基础科目达标，部分专业（如护理、设计）有附加面试或作品集要求。
ELR2B2 是什么？分数怎么算？
ELR2B2 是 O-Level 升理工学院（JAE）的核心分数：英文（EL）+ 2 门相关科目（R2）+ 2 门最佳科目（B2），共 5 科之和，越低越好，可减 CCA 加分。大部分专业要求净分 ≤26，护理类（ELR2B2-C）放宽到 ≤28。具体每个专业的录取分见专业录取分数据库。
理工 Diploma 毕业能升大学吗？
能，而且是主流去向之一。Diploma 毕业凭 GPA 可申请 SIT、NUS、NTU、SMU、SUTD 及英国、澳洲等海外大学，部分对口专业可获学分减免，最快 2 年完成本科。理工不是「终点」，而是通往大学的另一条路。
理工学院读几年？学费多少？
全日制 Diploma 一般 3 年（含实习）。国际学生申请 MOE 学费津贴后约每年 S$11,000 左右（需签毕业后在新加坡工作 3 年的服务协议）；不申请津贴则更高。另需预算生活费、住宿与保险，整体仍比英美澳本科性价比高。
5 所理工怎么选？各自强在哪？
看专业方向：SP 海事 / 视光 / 航空全国唯一、工程老牌；NP 传媒 / 电影、护理、商科强；NYP 护理 / 健康科学最强、教学工厂产业实战；TP 设计 / 兽医技术（全国唯一）、临湖校园；RP 问题导向学习 PBL、体育 / 酒店 / 航空。同一专业不同理工分数差别大，建议用数据库横向对比。
没有 O-Level 的国际学生怎么进理工？
可走两条路：① 参加 AEIS / 同等英文与数学测试，或先读 O-Level 预备 / Foundation 预科再考 O-Level；② 凭高中成绩 + 校方测试直接申请部分理工的国际学生通道。具体门槛各校各专业不同，建议先做学历评估。
理工学院毕业好就业吗？
新加坡理工 Diploma 在本地就业市场认可度高，很多专业（护理、工程、IT、酒店等）毕业即可对口就业，实习也常转正。多数学生会「先升学、后就业」或「边工作边读 part-time 学位」，路径灵活。
男生读理工需要服兵役（NS）吗？
新加坡籍及部分 PR 男生需服兵役，通常在 Diploma 毕业后入伍，再升学或就业；国际学生（如中国学生）不需要服兵役，不受 NS 影响。
