AEIS（Admissions Exercise for International Students）考试当天，往往是家长一整年备考中最焦虑的节点。准备再充分，现场的一个细节疏忽——忘带护照、迟到几分钟、填错答题卡——都可能让数月的努力付诸东流。本文从入场流程、物品清单、科目策略到考场禁忌，逐项拆解 AEIS 考试日的完整操作手册。

## AEIS 考试当天完整时间线

AEIS 考试通常安排在 9 月或 10 月进行，考试地点由新加坡教育部（MOE）统一指定，一般为新加坡博览中心（Singapore Expo）或指定政府学校。以下为考试日标准流程：

| 时间节点 | 事项 | 关键提醒 |
|---------|------|---------|
| 07:00-07:30 | 抵达考场 | 提前1小时以上到达，预留找考场与交通拥堵时间 |
| 07:30-08:00 | 入场核验 | 出示护照原件与 Entry Proof，核验考生身份 |
| 08:00-08:15 | 入座准备 | 按座位号入座，检查文具，禁止交谈 |
| 08:15-08:30 | 监考宣读规则 | 发放答题卡，填写个人信息（英文姓名、准考证号） |
| 08:30-10:45 | 英文考试（Paper 1 + 2） | 小学组约2小时，中学组约2小时15分 |
| 10:45-11:15 | 中场休息 | 可在指定区域饮食，不可离场太远 |
| 11:15-13:15 | 数学考试 | 小学组约1.5-2小时，中学组约2-2.5小时 |
| 13:15 | 考试结束 | 按指令有序离场，带走所有个人物品 |

## 必带物品核对清单

![AEIS考生必备物品与文具展示](/assets/articles/aeis-exam-day-guide-mid.png)

以下为 AEIS 考场必须携带的物品，缺一不可。每年都有考生因证件不全被拒绝入场。

| 类别 | 物品 | 要求说明 |
|------|------|---------|
| 身份证明 | 护照原件 | 必须与报名时使用的护照一致，需在有效期内 |
| 考试凭证 | Entry Proof（准考证） | 彩色打印，信息清晰可辨，不可折叠模糊 |
| 考试凭证 | 学生准证（STP/DP/LTVP） | 如适用，携带原件 |
| 文具 | 2B 铅笔（至少3支） | 削好备用，答题卡必须使用 2B 铅笔填涂 |
| 文具 | 橡皮擦 | 干净无包装，用于修正答题卡填涂错误 |
| 文具 | 黑色/蓝色水笔（至少2支） | 用于英文写作部分，不可使用铅笔作答作文 |
| 文具 | 透明铅笔袋 | 考场要求文具装在透明袋中，不透明笔袋禁止带入 |
| 个人物品 | 手表（非智能） | 部分考场无挂钟，建议自带普通指针手表 |
| 饮食 | 矿泉水（透明瓶） | 撕掉外包装标签，透明瓶身 |
| 饮食 | 简单零食 | 巧克力、饼干等，中场休息补充能量 |

## 考场禁止物品清单

下列物品严禁带入考场。一旦被发现携带，轻则没收，重则取消考试成绩。

| 禁止物品 | 说明 |
|---------|------|
| 手机及电子设备 | 含智能手表、平板、Kindle 等，须关机后交由家长保管或放入考场指定存放处 |
| 计算器 | AEIS 数学考试禁止使用任何类型计算器 |
| 字典、电子词典 | 英文考试不得查阅任何参考资料 |
| 修正液/修正带 | 答题卡涂改只能用橡皮，写作修改直接划线删除 |
| 带文字标签的文具 | 笔杆上印刷了公式、单词的文具禁止使用 |
| 不透明笔袋/背包 | 随身包须放在考场指定位置，不可带至座位 |
| 食物（考试期间） | 仅中场休息时可以饮食，考试中不可进食 |

## 各科目考试策略与时间分配

AEIS 考试分为英文和数学两科，小学组（P2-P5）和中学组（Sec1-Sec3）的难度与题量差异明显。

### 小学组（Primary 2-5）时间分配

| 科目 | 题型 | 建议时间分配 | 注意事项 |
|------|------|-------------|---------|
| 英文 Paper 1（写作） | 看图写话/命题作文 | 30-40分钟 | 先列提纲再动笔，留5分钟检查拼写和语法 |
| 英文 Paper 2（理解与语言应用） | 阅读理解、语法填空、词汇选择 | 60-70分钟 | 先做语法和词汇题（得分快），阅读理解放最后 |
| 数学 | 选择题 + 简答题 + 应用题 | 90-120分钟 | 先通览全卷评估难度，标记卡住题目后跳过 |

### 中学组（Secondary 1-3）时间分配

| 科目 | 题型 | 建议时间分配 | 注意事项 |
|------|------|-------------|---------|
| 英文 Paper 1（写作） | 议论文/记叙文（二选一） | 40-50分钟 | 选题花2分钟决定，论证须有具体例子支撑 |
| 英文 Paper 2（理解与语言应用） | 阅读理解（2篇）、语法改错、词汇填空 | 70-80分钟 | 阅读理解先读问题再回原文定位，语法改错逐句排查 |
| 数学 | 选择题 + 简答题 + 长答题 | 120-150分钟 | 证明题/长答题须写完整步骤，仅给最终答案不得过程分 |

### 小学组与中学组考试差异对比

| 对比维度 | 小学组（P2-P5） | 中学组（Sec1-Sec3） |
|---------|---------------|-------------------|
| 考试总时长 | 约3.5-4小时 | 约4.5-5小时 |
| 英文写作要求 | 80-120词 | 200-350词 |
| 数学难度对标 | 国内同年级水平 | 国内同年级+部分超纲内容 |
| 数学可用计算器 | 否 | 否 |
| 中场休息 | 有（约30分钟） | 有（约30分钟） |
| 答题卡格式 | 选择题涂卡 | 选择题涂卡 + 手写作答 |

## 常见突发情况及应对

| 突发情况 | 应对方案 |
|---------|---------|
| 忘带护照 | 立即联系考场工作人员与 MOE 热线，家人尽快送原件到考场 |
| 迟到 | 迟到15分钟内通常允许入场（部分考场严格禁止），超过30分钟大概率拒绝入场 |
| 身体不适 | 立即举手示意监考老师，考场有急救人员。考试中离场上厕所须有监考陪同 |
| 答题卡填错 | 用橡皮彻底擦除重新填涂，不要涂改液覆盖。个人信息填错须联系监考更换新卡 |
| 试题印刷不清 | 在座位上举手，监考会协助确认或更换试卷 |
| 忘带铅笔/橡皮 | 举手向监考求助，考场通常备有少量备用文具 |

## 考试结束后家长该做什么

| 时间节点 | 事项 | 说明 |
|---------|------|------|
| 考试当天 | 不谈成绩 | 不要追问"考得怎么样"，让孩子放松 |
| 考后1-2周 | 关注 MOE 通知 | 留意邮件与 AEIS 报名系统消息 |
| 考后4-8周 | 成绩公布 | 通常在11月-12月公布录取结果 |
| 收到录取 | 办理入学手续 | 按学校通知办理学生证、购买校服、课本 |
| 未获录取 | 评估备选方案 | 可考虑次年 S-AEIS、国际学校或私立学校路径 |

## 常见问题

### AEIS 考试当天几点到达合适？

建议 07:00-07:30 抵达考场。新加坡早高峰交通拥堵（尤其 PIE/CTE 方向），且 Expo 考场面积大，找到具体考室需要时间。家长前一晚应提前规划路线，乘地铁（MRT）的考生在 Expo 站（CG1/DT35）下车步行约5-8分钟可达。

### Entry Proof 丢了怎么办？

Entry Proof 可从 AEIS 报名系统中重新下载打印。考试当天丢失的，考场外通常设有 MOE 咨询台，凭护照原件可申请临时验证入场。强烈建议打印2份分开存放，一份随身携带，一份放家长包里备份。

### 考试中间可以上厕所吗？

可以，但须举手经监考老师同意，由工作人员陪同前往。上厕所时间计入考试用时，不会额外补偿。建议考前少喝水，中场休息时再去。

### 忘记带 2B 铅笔考场有备用的吗？

部分考场备有少量应急文具，但不保证。正确做法是前一晚核对物品清单，至少携带3支削好的 2B 铅笔和2块橡皮。建议准备两个透明铅笔袋，一份主用一份备用。

### 多选题答题卡怎么填才不扣分？

使用 2B 铅笔将选项对应的圆圈完全涂黑，涂改时用橡皮擦干净再重新填涂。常见的扣分原因是：涂得太浅机读不到、修改未擦干净造成多选、涂出圆圈外。考前可让孩子用模拟答题卡练习几次。

### AEIS 数学可以用计算器吗？

不可以。AEIS 小学组和中学组的数学考试均禁止使用计算器。中国学生在国内已经习惯了手算，这一点反而是优势。平时练习时就应以手算为主，不要依赖计算器。

### 考完 AEIS 多久出成绩？

AEIS 成绩通常于考试后 4-8 周公布（11月-12月间）。录取结果通过邮件和在 AEIS 报名系统中发布。只公布"通过/未通过"及录取学校，不公布具体分数。

### 万一没考上，下一步怎么走？

未通过 AEIS 的考生可申请次年 2-3 月的 S-AEIS 补考，或选择新加坡国际学校、私立学校等备选路径。关于 S-AEIS 与 AEIS 的具体区别、难度差异和报名条件，可参考 [S-AEIS 与 AEIS 详解对比](/aeis/s-aeis-vs-aeis/)。
