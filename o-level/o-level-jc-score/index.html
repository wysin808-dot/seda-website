O-Level成绩公布后的第一个问题，几乎所有家长都会问：孩子这个分数，能进哪所JC？

这不是一个简单的"多少分够"的问题。新加坡初级学院（JC）的录取不是划一条统一的及格线，而是每所JC、每个学科方向（文科/理科）都有独立的截分点（Cut-off Point）。本文基于MOE最新录取数据，系统梳理L1R5计分规则、各JC分数线、减分政策与国际学生申请要点。

L1R5计分规则：JC录取只看这个分数

O-Level申请JC的录取依据是L1R5总分。分数越低越好——满分6分（全A1），理论最高26分。

L1R5六科拆解

代码含义可选取科目范围
L1第一语言英文（English Language）或高级母语
R1第一相关科目人文科目：综合人文（Social Studies+选修）、地理、历史、英文文学、中文文学
R2第二相关科目数学/科学：基础数学（E.Math）、附加数学（A.Math）、物理、化学、生物、综合科学
R3最佳科目三剩余科目中成绩最好的一门
R4最佳科目四剩余科目中成绩最好的一门（不含R3已选）
R5最佳科目五剩余科目中成绩最好的一门（不含R3、R4已选）

> 核心点：L1必须是英文（对绝大多数学生）。R1必须包含一门人文。R2必须包含一门数学或科学。剩下R3-R5从剩余科目中取最佳三门即可。

L1R5计算示例

假设一名中国学生O-Level成绩如下：

科目等级积分计入L1R5
英文（English）B33L1 = 3
综合人文B44R1 = 4
E.MathA11R2 = 1
A.MathA22R3 = 2
物理A22R4 = 2
化学B33R5 = 3

原始L1R5 = 3 + 4 + 1 + 2 + 2 + 3 = 15分

减分政策：最高可减4分

新加坡MOE提供两种合法减分途径，合计最高可减4分：

减分途径条件减分额度中国学生适用性
高级华文高级华文（Higher Chinese）达D7及以上减2分✅ 中国学生几乎必拿
CCA优秀课外活动（CCA）成绩达"Excellent"减2分⚠️ 需至少2-3年持续参与
CCA良好课外活动（CCA）成绩达"Good"减1分⚠️ 需至少1-2年参与

实际录取分 = 原始L1R5 − 高级华文减免 − CCA减免

以上述学生为例：原始L1R5 = 15分 → 如有高级华文减免减2分 → 净分 = 13分，可竞争裕廊先驱初院等学校。

中国家长常在这个节点纠结。下表从多个维度对比两条路径：

维度JC（初级学院）Poly（理工学院）

后续路径A-Level → 大学Diploma → 就业或凭GPA升大学

常见问题

L1R5不达标（>20分）还能申请JC吗？

可以尝试直接向个别JC提出申诉（Appeal），尤其是截分点在18-20分的学校。但成功率较低，建议同步准备Poly申请或私立学校备选方案。每年有少数因CCA/领导力突出获特例录取的学生。

高级华文减分有什么条件？中国学生怎么操作？

条件很简单：O-Level高级华文（Higher Chinese）成绩达D7及以上，在JAE填报时系统自动减2分。中国学生只要修读了高级华文且正常参考，基本都能拿到这2分。如果以私人考生身份参加O-Level，需要确保在SEAB报名时选报了高级华文科目。

中国学生英文总是拖后腿，有没有英文要求低的JC？

所有JC均以英文为L1计入L1R5，不存在"英文要求低"的JC。英文每提高一个等级（如C6→C5→B4），L1R5直接减1分。对于英文偏弱的学生，建议目标定为英文B4，配合数理A1优势，总体L1R5控制在15分以内。

JC录取看哪几科？可以选考7-8科吗？

L1R5只看6科成绩。考7-8科不影响录取，但第7、8科不计入L1R5（除非前6科中有D7以下须替换）。MOE建议学生集中精力确保核心6科，避免贪多导致整体下滑。

国际学生用O-Level成绩能申请海外大学吗？

可以。O-Level成绩被英联邦、澳洲、加拿大等广泛认可。部分澳洲大学（如悉尼大学、墨尔本大学预科）直接用O-Level成绩录取。但JC只是中间站——实际申海外大学看的是A-Level或IB最终成绩，O-Level是申请JC的工具。

Poly毕业后还能转JC吗？

不能直接转。但Poly毕业生可凭GPA申请大学，路径与JC毕业生不同。如果已经在Poly但在第一年发现不适合，部分学生选择退学重读O-Level或直接申请私立预科。这类操作成本较高，建议在O-Level出成绩时就慎重决策。
