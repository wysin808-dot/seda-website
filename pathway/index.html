路径全景

三条路，各有出口

中国学生赴新加坡留学，核心路径可以归纳为三大方向。每条路径的入口、课程体系、考试方式和最终升学出口都不同。家长首先要看清全景，再根据孩子的年龄、英文水平和目标大学做选择。

三条路径并非"好坏之分"，而是"适配之别"。关键变量是：孩子的当前年龄、英文水平、数学基础、目标大学和家庭预算。没有最好的路径，只有最适合的路径。

选路径的核心逻辑 先确定目标大学和专业 → 倒推需要什么成绩 → 再看孩子现在的年龄和英文水平 → 最后选择最可行的路径和学校。
三大路径

选哪条路？先看入口和出口

每条路径的入学方式、课程体系和大学出口都不同。以下是三条主路径的核心概览，点击相关链接深入了解。

政府学校路线 01

AEIS → O-Level → JC / Poly

通过 AEIS 考试进入政府中小学，完成 O-Level 后升入 JC（A-Level）或 Poly（理工学院），再申请本地大学。费用最低，本地认可度最高。

国内学生 → AEIS 考试 → 政府中小学 → O-Level → JC / Poly → 大学
AEIS 攻略 O-Level 攻略 JC 路径 Poly 路径
私立学校路线 02

WACE Year 10–12 → ATAR → 大学

无需 AEIS，进入新加坡私立学校修读西澳 WACE 课程，获得 ATAR 排名成绩，申请新加坡、澳洲、英国、香港大学。数学友好，有英文过渡。

国内学生 → 私立学校入学 → WACE Year 10–12 → ATAR → 全球大学
WACE 完全攻略 WACE 申请 NUS/NTU 私立学校库
国际学校路线 03

IGCSE → IB / A-Level → 全球大学

直接入读新加坡国际学校，修读 IB Diploma 或 A-Level，面向全球顶尖大学申请。学术训练全面，英美名校认可度最高，但学费最贵。

国内学生 → 国际学校入学 → IGCSE → IB / A-Level → 全球大学

如何选择

做决定前，先想清楚这三件事

路径选择没有标准答案，但有清晰的决策框架。以下三个维度是最核心的考量，建议家长在咨询前先自我评估。

🎓

目标大学是哪里？

目标是新加坡 NUS/NTU，A-Level 是主通道，WACE ATAR 也被接受。目标是澳洲八大，WACE ATAR 直接对接。目标是英美名校，IB 或 A-Level 是首选。先定目标，再选路径。

📅

孩子现在几岁？

年龄决定时间窗口。12 岁以下三条路都可以走；15 岁以上时间紧迫，WACE 是最高效的转轨路径；18 岁以上可考虑 Foundation 预科直接衔接大学。

🗣️

英文水平怎么样？

英文强可以考虑所有路径；英文中等优先看 WACE（有 EALD 过渡）；英文基础弱需要先做语言强化，再选路径。不要因为英文弱就放弃留学，但也不要高估孩子的适应能力。

常见问题

家长最常问的五个问题

以下是咨询过程中家长最频繁提出的问题，直接给出结论，不绕弯子。

中国学生去新加坡留学有哪些主要路径？

主要有三条：一是政府学校路线，通过 AEIS 考试进入政府中小学，走 O-Level → JC/Poly 体系，费用最低；二是私立学校 WACE 路线，无需 AEIS，修读西澳高中课程获得 ATAR 成绩申请大学，数学友好；三是国际学校路线，修读 IB、A-Level 或 IGCSE，面向全球大学申请，学费最高。

不同年龄段的孩子应该选哪条留学路径？

7–12 岁优先考虑 AEIS 进政府小学；13–15 岁可选政府中学或私立学校过渡；15–16 岁是关键分水岭，走 O-Level 或 WACE Year 10–11 均可，但时间紧迫需尽早决策；16–18 岁从国内转轨，WACE Year 11 是最高效选择，英文强的可考虑国际学校 IB。

WACE 和 O-Level 路径哪个更适合中国学生？

没有绝对优劣。O-Level 路径费用低、本地认可度高，但需通过 AEIS 且周期长；WACE 无需 AEIS、数学友好、有 EALD 英文过渡，适合英文中等、数理基础扎实、目标澳洲或新加坡大学的学生。选择取决于孩子年龄、英文水平和目标大学。

想申请 NUS/NTU，应该选什么路径？

A-Level（JC 路径）是 NUS/NTU 的主通道，认可度最高。WACE ATAR 也被 NUS/NTU 接受，热门专业通常需要 ATAR 90+。IB 同样被广泛接受。建议根据孩子的英文水平和当前年龄选择最可行的路径，而不是单纯追求认可度最高的路径。

新加坡留学各路径费用差多少？

政府学校学费最低，约 SGD 7,000–9,000/年；私立学校 WACE 路径约 SGD 15,000–25,000/年；国际学校最贵，约 SGD 30,000–50,000/年。此外还需计算住宿（SGD 800–2,000/月）、生活费等，建议按完整留学周期做预算规划。详见 新加坡留学费用指南。
