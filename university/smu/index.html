学校概况

新加坡管理大学（Singapore Management University，SMU）成立于 2000 年，是新加坡第三所公立大学，办学之初即对标美国沃顿等顶尖商学院，主打商科、会计、法律、经济与计算机。

SMU 最大的特色是市中心校区 + 100% 研讨式教学：校园位于 Bras Basah / Bencoolen 市中心，紧邻金融与商业区；课堂采用小班（多≤45 人）互动研讨，没有传统大课，强调思辨、表达与团队协作。约 1.2 万名本科生。

在 QS 学科排名中，SMU 的商科与管理跻身全球前 40、会计与金融进入全球前 50，会计科研更是全球第一，并被评为 QS 学科排名「全球进步最快」的大学。对想读商科、会计、金融、法律的中国学生，SMU 是除 NUS/NTU 外极具吸引力的选择。

常见问题

SMU 高考多少分能进？
SMU 接受高考，商科 / 会计 / 法律门槛很高，通常要求远超一本线，并看英文与综合素质；部分专业有写作或面试评估。高考过线只是入门，最终按全体国际申请者择优。
SMU 和 NUS / NTU 怎么选？
如果目标是商科、会计、金融、法律，且喜欢互动研讨、市中心区位与强实习，SMU 非常对口；想读工程、医学、纯理科则看 NUS / NTU。SMU 是专才型商管名校，NUS / NTU 是综合研究型大学。
SMU 国际学生一年学费多少？
国际学生不申请津贴约每年 S$47,700 起（法学约 S$56,150）；申请 MOE 津贴后明显更低，但须签毕业后在新加坡工作 3 年的服务协议。另需预算市中心住宿与生活费。
SMU 的「研讨式教学」是什么？
SMU 100% 采用小班研讨式课堂（多不超过 45 人），没有传统大课，课堂发言与互动计入成绩，特别锻炼思辨、表达、汇报与领导力——这也是 SMU 区别于其他大学的最大特色。
SMU 最强 / 最热门的专业是哪些？
会计、工商管理、法律、经济、计算机、信息系统都是录取分高或最热门的一档。具体录取线见大学专业录取分数据库。
理工 Diploma 毕业能进 SMU 吗？
能。SMU 收理工生，按 GPA 加综合素质竞争，多数专业 IGP 的理工 GPA 在 3.6–3.9。先在理工专业数据库选对 Diploma，再升 SMU 商科 / 计算机。
SMU 校区在哪？
SMU 是市中心整体校区，位于 Bras Basah / Bencoolen，地下连通地铁与商场，紧邻国家图书馆、博物馆与金融商业区，实习就业近水楼台。
SMU 有奖学金吗？
有。面向尖子有多类入学奖学金，覆盖学费甚至生活费，竞争激烈、需单独申请，看成绩 + 领导力 + 面试表现。
SMU 就业怎么样？
SMU 毕业生就业力与起薪常年居全国前列：2024 年应届月薪中位约 S$4,600、平均约 S$5,057，大量进入投行、四大、律所、咨询与科技名企。
SMU 适合内向的学生吗？
SMU 课堂高度互动、需要大量发言与汇报，对表达与团队协作要求高。内向但愿意锻炼表达的同学很适合（会快速成长）；若完全抗拒发言，可能要慎重考虑。
