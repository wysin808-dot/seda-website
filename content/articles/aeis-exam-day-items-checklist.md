AEIS 考试当天，证件不齐或误带违禁物品可能导致无法入场。每年都有中国考生因文具不合规被监考官要求现场更换，甚至因携带手机而被取消全部成绩。以下清单基于新加坡考试与评鉴局（SEAB）官方考场规则整理，逐项核对即可确保零意外入场。

## AEIS 考试当天必备物品清单

以下物品缺一不可。建议考试前一晚按表逐项核对并装入透明文件袋中，当天直接携带入场。

| 物品类别 | 具体要求 | 注意事项 |
|---------|---------|---------|
| 护照原件 | 有效期须覆盖考试日期 | 不接受复印件或过期护照，照片须清晰可辨认 |
| 学生准证（如有） | STP 原件，非复印件 | 已在新加坡就读的国际学生须携带 |
| AEIS 准考证 | 彩色打印件，A4 纸 | SEAB 通过电子邮件发送，条形码区域不可折叠或污损 |
| 2B 铅笔 | 至少 3 支，削尖 | 用于填涂答题卡；自动铅笔可接受但须使用 2B 铅芯 |
| 黑色或深蓝色签字笔 | 至少 2 支 | 用于作文及主观题作答；不可使用可擦笔、荧光笔或圆珠笔 |
| 橡皮擦 | 白色软质，去除外包装 | 不可使用带涂改功能的橡皮（如橡皮笔、沙橡皮） |
| 卷笔刀 | 小号手动款 | 电动卷笔刀不允许带入考场 |
| 透明直尺 | 15cm 或 30cm | 不可带有任何公式、表格或图案印刷 |
| 透明水瓶 | 矿泉水瓶揭除外标签 | 仅允许白水；有色饮料、保温杯、运动水壶均禁止 |
| 外套 | 素色无文字图案 | 考场空调温度通常偏低；外套不可带有英文单词、数字或品牌 logo |

## AEIS 考场绝对禁带物品

SEAB 对违禁物品执行"零容忍"政策——一经发现，轻则单科成绩作废，重则取消全部科目并记录考试违规档案。以下为完整禁带清单：

| 禁带物品 | 具体范围 | 处罚后果 |
|---------|---------|---------|
| 手机/智能手表/手环 | 含关机状态、飞行模式 | 取消全部科目成绩，记入 SEAB 违规档案 |
| 任何电子设备 | 平板、MP3、电子词典、翻译笔、录音笔 | 取消本场考试成绩 |
| 计算器 | 科学计算器、图形计算器均禁止 | AEIS 数学考试明确禁止使用计算器 |
| 修正带/修正液/可擦笔 | 任何涂改工具 | 没收处理；作文中若被发现使用可能影响评分 |
| 自带草稿纸 | 包括空白纸、便签纸 | 考场统一配发草稿纸；自带任何纸张视为作弊 |
| 教科书/笔记/公式表 | 任何印刷或手写参考资料 | 视为作弊，取消全部成绩 |
| 不透明文具盒/笔袋 | 任何非透明容器 | 须全部换成透明文件袋方可入场 |
| 食品/糖果/口香糖 | 包括润喉糖 | 除白水外禁止饮食 |
| 有文字图案的衣物 | T恤、外套上的英文、数字、卡通 | 需更换为纯色衣物方可入场 |

## AEIS 考试文具规格详解

中国文具与新加坡考场要求的差异是历年考生踩坑最多的环节。以下对照表列出常见误区：

| 文具类型 | 新加坡考场要求 | 中国常见误区 | 合规建议 |
|---------|-------------|-------------|---------|
| 铅笔 | 2B 铅笔，黑色铅芯 | 使用 HB 铅笔填涂（颜色偏浅，可能扫描不识别） | 选用中华 2B 或 Staedtler 2B，提前削好 |
| 自动铅笔 | 2B 铅芯可接受 | 使用 HB 铅芯的自动铅笔 | 购买 2B 规格铅芯并确认包装标注 |
| 签字笔 | 黑色或深蓝色，不可擦 | 使用可擦笔、蓝色圆珠笔、荧光笔 | 选用 Pilot G2 0.5mm 黑色或 Uni-ball 深蓝色 |
| 橡皮 | 白色软质 | 彩色橡皮、沙橡皮（可能留痕） | 选用 Staedtler Mars Plastic 或 Faber-Castell |
| 修正工具 | 完全禁止 | 习惯使用修正带/修正液 | 答题时直接划线删除错误部分，在旁边重写 |

## AEIS 小学组与中学组考试物品差异

小学组（P2/P3/P4/P5）和中学组（Sec 1/Sec 2/Sec 3）考场要求基本一致，但存在以下细微差异：

| 差异项 | 小学组（P2-P5） | 中学组（Sec 1-3） | 说明 |
|-------|--------------|-----------------|------|
| 准考证格式 | 含家长陪同信息 | 无家长信息栏 | 小学组家长需在场外等候 |
| 数学草稿纸 | 统一发放，按需补充 | 统一发放，限量 | 中学组题量更大，草稿需合理规划使用 |
| 英文作文 | 无额外文具要求 | 部分考场允许携带英汉词典（仅限纸质词典，须提前向 SEAB 申报） | 中学组英文难度更高，词典审批周期约 2 周 |
| 数学工具 | 直尺即可 | 直尺、圆规（部分考场允许） | 中学组几何题可能涉及画圆，须提前确认考场规则 |

## 考前物品准备时间表

避免考前临时慌乱，以下时间表覆盖从报名确认到考试当天全流程：

| 时间节点 | 需准备物品 | 操作要点 |
|---------|----------|---------|
| 考前 2 周 | 准考证打印 | SEAB 邮件通常在考前 10-14 天发出，收到后立即彩色打印 2 份 |
| 考前 1 周 | 护照检查 | 确认有效期覆盖考试日期；如过期须立即联系中国驻新使馆办理旅行证 |
| 考前 3 天 | 文具采购 | 按本文规格表一次性购齐所有文具，多备 2 份以防临时丢失 |
| 考前 1 天 | 逐项核对 | 全部物品装入透明文件袋，按清单勾选；确认考场地址和交通路线 |
| 考试当天出发前 | 最终检查 | 再次核对护照+准考证+文件袋；手机务必留在住处或交给陪同家长 |
| 抵达考场后 | 寄存非必要物品 | 手机/书包等交给陪同人员或存放于考场指定区域；仅携带透明文件袋入场 |

## 常见问题

### AEIS 考试可以带自己的草稿纸吗？

不可以。SEAB 明确规定考场统一配发草稿纸，考生自带任何纸张均被视为作弊行为。草稿纸在每科考试开始时发放，如需额外纸张可举手向监考官申请。考试结束后草稿纸须与试卷一并交回，不得带离考场。

### 如果忘记带准考证怎么办？

准考证是入场的核心凭证，无准考证不得进入考场。建议打印至少 2 份彩色副本，一份随身携带、一份交由陪同家长保管。如当天确实遗忘且居住地较远，可尝试联系考场工作人员——部分考场在核实身份后允许入场，但这不是标准流程。更稳妥的做法是考前将准考证电子版存入手机备份（入场前手机需寄存）。

### AEIS 数学考试真的不能用计算器吗？

确认禁止。AEIS 数学考试（无论小学组还是中学组）全程禁止使用任何类型的计算器。所有计算须手算完成。这与新加坡本地校内考试（O-Level 等允许计算器）不同，中国考生须特别注意。备考阶段即应养成脱离计算器的习惯，重点训练心算和笔算速度。

### 可以带手表进考场吗？

普通指针式手表可以，但智能手表/手环/电子表一律禁止。最安全的做法是不佩戴任何手表入场——考场内通常有挂钟供考生参考时间。如确需佩戴，选择最简单的指针式石英表，且表盘不可有任何计算或存储功能。

### 修正带被没收会影响成绩吗？

修正带在入场检查时会被要求丢弃或寄存，不影响成绩。但如果在考试过程中被监考官发现使用修正带，则可能被记录违规——尤其作文部分，使用修正带后卷面异常痕迹可能触发评分质疑。建议从备考阶段即改掉依赖修正带的习惯，练习直接划线删除错误内容的作答方式。

### 考试中途可以上厕所吗？

可以，但须举手向监考官申请并由工作人员陪同。上厕所时间计入考试时间，不会额外补时。建议考前控制饮水量，考前去一次洗手间，避免影响答题节奏。

### 不同科目的文具要求有区别吗？

英文作文和数学选择题均使用 2B 铅笔填涂答题卡，英文主观题使用黑色签字笔作答。小学组和中学组的文具要求基本一致，仅中学组数学可能涉及需要圆规的几何题——建议考前向 SEAB 或所在考场确认。
