## ⚠️ Critical Fix: seda.org.sg Canonical

`seda.org.sg` 是 Vercel 部署的镜像站，Google 已收录 200+ 页。但没有 canonical 指向 `sgeda.org.cn`，这是**重复内容惩罚**的隐患。

**修复方法：** 在 Vercel 项目的构建脚本中，给所有页面加：
```html
<link rel="canonical" href="https://sgeda.org.cn/[path]/">
```

或将 seda.org.sg 301 重定向到 sgeda.org.cn（更彻底）。
