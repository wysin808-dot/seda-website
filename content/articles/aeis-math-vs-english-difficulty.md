"数学简单、英文太难"是绝大多数参加AEIS考试的中国家庭的直观感受。但事实是否如此？在实际考试中，数学部分存在全英文题干的理解陷阱，英文部分又因新加坡本地化的题型设计让中国考生措手不及。本文从考试结构、得分数据、词汇量门槛和备考策略四个维度，对两科做一次全面对比。

## AEIS 数学与英文考试结构全景对比

| 对比维度 | AEIS 数学 | AEIS 英文 |
| 考试时长 | 小学2小时/中学2小时15分 | 小学2小时/中学2小时30分 |
| 题型构成 | 选择题 + 简答题 + 应用题 | 选择题 + 完形填空 + 阅读理解 + 作文 |
| 语言媒介 | 全英文出题 | 全英文 |
| 核心能力要求 | 数学推理 + 英文读题能力 | 词汇语法 + 阅读理解 + 写作表达 |
| 中国学生优势 | 数学基础扎实，知识点领先1-2年 | 语法基础好，阅读训练有素 |
| 中国学生短板 | 英文术语不熟、应用题题干理解 | 词汇量不足、作文逻辑表达弱 |
| SEAB官方评分权重 | 50% | 50% |

两科权重相同，但中国学生的实际得分分布呈现显著分化。

## 中国学生眼中——AEIS 数学到底难不难？

单论数学知识点，AEIS 数学对中国学生确实不难。但全英文出题改变了这一点。

### AEIS 数学知识点与中国年级对照

| AEIS 考试级别 | 对应国内年级 | 核心知识点 | 中国学生掌握度 |
| 小学P2/P3 | 国内二年级 | 四则运算、简单分数、长度/重量单位 | ✅ 熟练掌握 |
| 小学P4/P5 | 国内三至四年级 | 分数运算、小数、面积周长、基础几何 | ✅ 熟练掌握 |
| 中学Sec 1 | 国内五至六年级 | 代数基础、方程、比例、统计图表 | ✅ 大部分掌握 |
| 中学Sec 2 | 国内初一 | 线性方程、不等式、勾股定理、概率 | ✅ 基本同步 |
| 中学Sec 3 | 国内初二 | 二次方程、三角函数入门、向量基础 | ⚠️ 部分超前 |

### 数学真正的失分点——英文读题

| 失分类型 | 占比 | 典型表现 | 解决方案 |
| 应用题理解偏差 | 40% | "altogether"误解为"其中之一" | 系统背诵数学术语表 |
| 英制单位不熟悉 | 25% | 英尺/英寸/磅与公制混淆 | 考前专项练习单位换算 |
| 图表题信息遗漏 | 20% | 忽略图表中标注的英文注释 | 训练图表+文字交叉阅读 |
| 解题步骤不规范 | 15% | 缺少Working/Unit扣步骤分 | 按新加坡评分标准练规范答题 |

## 中国学生真正的难关——AEIS 英文

英文是绝大多数中国考生被淘汰的原因。不是"有点难"，而是"断崖式差距"。

### AEIS 英文各模块难度拆解

| 模块 | 分值占比 | 中国学生平均得分率 | 核心难点 |
| 词汇与语法 | 30% | 65%-75% | 新加坡本地化词汇（如void deck, ERP） |
| 完形填空 | 15% | 50%-60% | 上下文逻辑衔接、固定搭配 |
| 阅读理解（选择题） | 25% | 55%-65% | 推断题和主旨题超国内同类难度 |
| 阅读理解（开放题） | 10% | 30%-40% | 用完整英文句子作答 |
| 作文 | 20% | 35%-45% | 议论文/记叙文结构，150-300词要求 |

### 词汇量——最直观的差距

| 参考标准 | 词汇量要求 | AEIS 对标水平 |
| 国内小学毕业 | 800-1000词 | 不足以应对P2/P3级别 |
| 国内中考 | 2000-2500词 | 勉强对应P4/P5级别 |
| 国内高考 | 3500-4000词 | 对应Sec 2/Sec 3级别 |
| 新加坡小六（PSLE） | 5000-6000词 | 超出国内初中水平 |
| 新加坡中二 | 7000-8000词 | 接近国内高中水平 |

## 两科通过数据揭示的备考优先级

| 数据指标 | AEIS 数学 | AEIS 英文 |
| 中国学生平均分（百分制） | 72-85分 | 48-58分 |
| SEAB 官方及格线附近占比 | 85%+ 通过 | 约40% 通过 |
| 短期内（3个月）可提分幅度 | 10-15分（主攻术语和题型） | 5-10分（词汇和模板突击） |
| 6个月系统备考提分潜力 | 15-20分 | 15-25分 |
| 对总录取结果的决定性 | "保底项"——拿高分拉平英文 | "一票否决项"——不及格直接淘汰 |

**结论：数学决定上限，英文决定下限。** 数学拿不到85分以上就失去了拉分的优势；英文不及格则直接失去录取资格。

## 不同起点学生的备考时间分配策略

| 学生起点类型 | 英文当前水平 | 每日英文时间 | 每日数学时间 | 总备考周期 |
| 英语强（国际学校在读） | 相当于新加坡同龄80%+ | 1小时 | 1小时 | 2-3个月 |
| 英语中等（国内重点/双语学校） | 相当于新加坡同龄50%-70% | 1.5-2小时 | 0.5-1小时 | 4-6个月 |
| 英语弱（国内普通学校） | 低于新加坡同龄50% | 2-2.5小时 | 0.5小时 | 6-12个月 |

## 英文备考中国学生最容易踩的三个坑

| 常见误区 | 为什么错 | 正确做法 |
| 只背单词不练阅读 | 孤立的词汇在语境中无法激活 | 每天精读1篇+泛读2篇，在文章中记单词 |
| 先攻语法再攻阅读 | 语法规则无法迁移到长难句理解 | 同步推进，用阅读材料中的句子学语法 |
| 考前一个月突击作文 | 写作需要语感积累，短期模板拿不到高分 | 从备考第一天起每周写1-2篇，逐篇修改 |

## 常见问题

### AEIS 数学满分多少？多少分算通过？

AEIS 不公布具体分数线，录取由SEAB根据当年考生整体表现和学额决定。数学满分因年级不同（P2/P3约50分，中学约100分）。根据历年经验，数学得分率在75%以上、英文得分率在50%以上才具备竞争力。

### AEIS 英文作文考什么类型？

小学阶段以记叙文和看图作文为主（100-150词），中学阶段以议论文和说明文为主（200-300词）。常见题目涉及校园生活、环境保护、科技影响等新加坡本地语境话题。

### 国内数学好的孩子可以直接裸考AEIS数学吗？

不推荐。即使数学基础扎实，全英文出题仍是障碍。建议至少花2-4周熟悉新加坡数学英文术语和题型格式，避免因"看不懂题"而非"不会做"而丢分。

### AEIS 两科有最低分要求吗？

SEAB未公布明确的单科最低分。但从录取实践看，任一一科明显低于平均水平都会导致淘汰。英文是筛选的第一关——英文不达标，数学满分也难录取。

### 备考时间有限，应该优先攻哪一科？

如果备考时间不足3个月：优先保数学（目标85分以上），英文维持及格线即可。如果有6个月以上：六成精力给英文、四成给数学。英文提分需要时间积累，越早开始效果越好。

### 小学和中学AEIS，哪个级别英文更难？

中学级别的英文难度呈指数级上升。中学Sec 2阅读理解篇幅是小五的2-3倍，作文词数要求翻倍（150→300词），且加入更多推断题和批判性思维题目。建议从低年级开始规划，避免高年级"硬着陆"。

### AEIS 英文用的词汇和国内学的一样吗？

不完全一样。新加坡英语使用大量本地化词汇（如hawker centre、void deck、MRT）和英式拼写（colour而非color、centre而非center）。考生需要熟悉至少200-300个新加坡本地高频词。
