学校概况

新跃社科大学（Singapore University of Social Sciences，SUSS）是新加坡第六所公立大学，2017 年正式升格（前身为 2005 年成立的新跃大学 UniSIM）。它以社会科学为核心，兼具商科、心理、传播与信息科技。

SUSS 最大的特色是多轮评估录取——全日制直入荣誉学位的申请者通常要经过写作 / 笔试、认知测试与按专业面试，看的不只是成绩，更是潜力、沟通与志向。这让有热情、有故事但分数未必拔尖的学生也有机会。

SUSS 在社会工作、幼儿教育、心理学、老年学、公共安全等方向尤其见长，强调应用与社会影响；商科（会计、金融、市场、人力、供应链、商业分析）也很扎实。校区位于 Clementi。对关注「人与社会」、想从事社工 / 教育 / 心理 / 商管的学生很对口。

常见问题

SUSS 是什么样的大学？
SUSS 是新加坡第六所公立大学（前身 2005 年新跃大学 UniSIM，2017 年升格），以社会科学见长——社工、幼教、心理、老年学、公共安全等方向强，商科也扎实，强调应用与社会影响。
SUSS 怎么录取？高考多少分？
SUSS 采用多轮评估录取：全日制荣誉学位通常需经写作 / 笔试 + 认知测试 + 按专业面试。高考成绩是参考，但更看潜力、沟通与志向——分数不是唯一标准。
SUSS 和其他公立大学怎么选？
如果你关注人与社会、想从事社工 / 教育 / 心理 / 公共服务或读商科，且愿意通过面试展示自己，SUSS 很对口；想读纯理工、医学、法律或看综合排名，则看 NUS / NTU 等。
SUSS 最强 / 最热门的专业是哪些？
社会工作、幼儿教育、心理学是 SUSS 的招牌；会计、金融、商业分析、公共安全等也很热门。具体专业见大学专业录取分数据库。
理工 Diploma 毕业能进 SUSS 吗？
能。SUSS 收理工生，凭 GPA 加多轮评估录取，社科 / 商科相关 Diploma 衔接好。可先在理工专业数据库选对方向。
SUSS 国际学生一年学费多少？
按专业不同；国际学生申请 MOE 津贴后明显降低，但须签毕业后在新加坡工作 3 年的服务协议；不申请津贴则更高。具体金额建议直接向 SUSS 招生确认。
SUSS 校区在哪？
SUSS 主校区位于 Clementi（463 Clementi Road），地处西部、交通便利，是社科与商科教学与实践基地。
SUSS 的多轮评估难吗？要准备什么？
多轮评估看重表达、思辨与志向：建议准备好个人故事、对专业的理解与社会关怀，练习写作与面试表达。它给有热情但分数未必拔尖的学生更多机会。
SUSS 就业怎么样？
毕业生进入社会服务机构、学校与幼教、心理与咨询、企业商管与政府公共部门；社工、幼教、心理等方向社会需求稳定、职业路径清晰。
SUSS 适合什么样的学生？
适合关注人与社会、想从事社工 / 教育 / 心理 / 公共服务或读商科，且愿意通过面试与评估展示潜力的学生；喜欢应用、实习与社会影响的人尤其对口。
